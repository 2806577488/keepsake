## 1. 会话列表（首页）

来源：`lib/features/sessions/sessions_screen.dart`

### 1.1 结构（从上到下）

| # | 区块 | 内容 | 何时出现 |
| --- | --- | --- | --- |
| 1 | **AppBar** | 左：多选按钮（`checklist` 图标）｜中：「留声」｜右：搜索 + 设置 | 常规态 |
| 2 | **AppBar（搜索态）** | 左：返回箭头｜中：输入框（hint「搜索标题或聊天内容」，自动聚焦）｜右：清空（有内容时） | 点了搜索 |
| 3 | **AppBar（多选态）** | 左：关闭 ✕｜中：「已选 N」｜右：全选 / 导出 / 删除 | 进入多选 |
| 4 | **导入进度条** | 一行进度文案 + 3px 进度条 + 当前会话标题 +「取消」 | 正在导入 |
| 5 | **导入失败条** | 「有 N 条没导上」+「重试没导上的」+ 关闭 ✕ | 导入跑完且有失败 |
| 6 | **列表** | `ListView.separated`，分割线缩进 72，底部留白 88 | 有会话 |
| 7 | **空态** | 64 大图标（`forum_outlined`）+「还没有会话」+「点右下角「新对话」开始，或从设置里导入 DeepSeek 的导出包」 | 0 条会话 |
| 8 | **FAB** | 「新对话」（`add_comment_outlined`，扩展式带文字） | 非搜索、非多选 |

### 1.2 列表行结构

一行 = `Dismissible` 包 `ListTile`（源码 `sessions_screen.dart:797` `_buildSessionTile`）：

| 位置 | 内容 | 细节 |
| --- | --- | --- |
| leading | 圆形头像 40 | 置顶 = `primaryContainer` 底 + `push_pin` 图标；普通 = `surfaceContainerHighest` 底 + `chat_bubble_outline` 图标 |
| title | 会话标题 | `titleMedium` w600，**最多 1 行**，超出省略号 |
| subtitle | 「5 天前 · 10 个对话」 | 相对时间 + 消息数，1 行省略 |
| trailing | 更多按钮 `more_vert` | 打开底部操作菜单 |
| 背景 | 分割线 `indent: 72`（和文字左缘对齐） | — |

**相对时间规则**（设计师注意文案空格）：`刚刚` / `N 分钟前` / `N 小时前` / `N 天前` / `M 月 D 日` / `YYYY 年 M 月 D 日`。7 天内用「天前」，超过 7 天用日期。数字和中文之间**有一个空格**。

### 1.3 交互（手势 → 结果）

| 手势 | 位置 | 结果 |
| --- | --- | --- |
| 点击 | 行 | 打开聊天页。**如果导入正在跑，会先把这条会话插到导入队列最前面**（用户点开哪条就先导哪条） |
| 长按 | 行 | **进入多选态**，并自动选中这一行 |
| 左滑（从右往左） | 行 | 露出 `errorContainer` 底 + 删除图标，松手弹确认框「「标题」及其消息会被删除，无法恢复。」 |
| 点击 | ⋮ | 底部菜单：会话标题+时间（不可点）→ 重命名 → 置顶/取消置顶 → 删除会话 → 为缺少角色卡的会话补建 |
| 点击 | 左上角 checklist | 进入多选态（未选中任何行）；**列表为空时 toast「还没有会话」，不进入** |
| 点击 | 「新对话」FAB | 新建会话并直接进入；创建中按钮变转圈 |
| 搜索框输入 | 搜索态 | 即时搜索（无需按回车），结果替换列表 |

> ⚠️ **多选入口在列表左上角，不在会话详情里**。历史版本曾把批量删除做成「对话框式列表」（见 `screenshots/t-batch2.png`），**已废弃**，不要再按那张图出稿。

### 1.4 多选态（这是用户明确要求过的形态）

| 区块 | 规则 |
| --- | --- |
| 顶栏标题 | 「已选 N」，N 实时变化 |
| leading | ✕ 关闭 → 退出多选并清空选择 |
| 全选按钮 | 图标在「全选 `select_all`」和「全不选 `deselect`」之间切换；**全不选 = 清空选择，不是退出多选** |
| 导出按钮 | `ios_share`；**0 选中时禁用**；导出中变转圈并禁用重复点击 |
| 删除按钮 | `delete_outline`；0 选中时禁用（图标也不再是红色）；有选中时图标转 `error` 红 |
| 行 leading | 变成 `Checkbox` |
| 行 trailing | **隐藏** ⋮（避免和勾选抢点击） |
| 行左滑 | **禁用**（`DismissDirection.none`，防误删） |
| 行点击 / 长按 | 都只是切换勾选 |
| FAB | 隐藏 |
| 搜索中 | **不能进入多选**（搜索态下多选入口不出现） |

**删除流程**：确认框（标题「删除会话」，正文「删除选中的 N 个会话？无法恢复」，取消 / 红色「删除 N 个」）→ 逐条级联删除（会话 + 该会话的用量记录 + 无主的角色卡）→ toast「已删除 N 个会话」→ 自动退出多选。

**导出流程**：底部弹层三选一 ——「存到手机」（选目录保存 ZIP）/「分享」（系统分享面板）/「取消」→ toast「正在导出 N 个会话…」→ 成功后「已保存到 …」或「已导出 N 个会话」。
两个出口都必须保留：存本地是离线备份，分享是发到别的 App（微信/网盘）。

### 1.5 搜索

- 搜索范围：会话标题 + 所有消息正文（含导入的历史消息）。
- 结果分两类：**标题命中**（`title` 图标，副标题「标题匹配 · 5 天前」）和**正文命中**（`chat_bubble_outline` 图标，标题是**命中片段**，最多 120 字，超出加「…」，副标题「会话标题 · 5 天前」）。
- 结果列表首行是分组标签「搜索结果」（`labelLarge`，`primary` 色）；分割线缩进 56。
- 点任一结果 → 进入该会话（**不自动定位到那条消息**，这是已知缺口）。
- 折叠复杂结构：命中正文里的图片/文件显示为 `[图片]文件名` / `[文件]文件名`，思考过程显示思考文本——统一压平成一行再截断。

### 1.6 空态与边界

| 情况 | 表现 |
| --- | --- |
| 0 条会话 | 大图标 +「还没有会话」+ 引导文案；**不额外放「新对话」按钮**（右下角 FAB 已经是入口，早期重复过） |
| 加载中 | 居中 `CircularProgressIndicator` |
| 加载失败 | 56 大图标（红 `error_outline`）+「加载失败」+ 错误详情 +「重试」描边按钮 |
| 搜索无结果 | 「没有找到包含「关键词」的内容」（居中，次要色） |
| 搜索词为空 | 居中提示「搜索标题或聊天内容」 |
| 标题超长 | 1 行省略号 |
| 0 个对话 | 副标题显示「0 个对话」（照实显示，不做特殊处理） |
| 一次删几百条 | 每 8 条让出一次事件循环，界面不冻结；单条失败不影响其余 |

### 1.7 导入进度与「后台任务」的关系（容易搞混）

- **列表顶部**：只显示**当前正在跑**的导入（进度 + 当前会话 + 取消）和**失败汇总**（有 N 条没导上 → 重试 / 关闭）。
- **查看全貌要去「设置 → 后台任务」**，那里同时列导入和「补建角色卡」两条任务。列表顶部不是后台任务面板。
- 「补建角色卡」的**启动入口在 ⋮ 菜单**（「为缺少角色卡的会话补建」），不在设置页 —— 设置页只负责显示进度。
- 导入中断（进程被杀/闪退）后重进 App 会自动断点续跑；顶栏会出现新的进度条。

| 数据 | Provider / 方法 |

| 搜索结果 | `sessionSearchQueryProvider` + `sessionSearchResultsProvider` |
| 导入进度 / 控制 | `importProgressProvider` / `importTaskProvider`（`core/import/import_task.dart`） |

### 1.9 待补 / 已知缺口

- **下拉刷新：未实现**。全工程没有任何 `RefreshIndicator`，列表靠数据库流自动更新。如果设计师要加下拉手势，需要同时确认「刷新语义」（重读数据库？还是重扫导入？）—— 建议先不做，避免暗示「远端有更新」。
- 搜索结果点进去**不定位到命中消息**，只打开会话。
- 列表没有「按角色卡分组」的视觉分组，角色卡只在设置里管理。

来源：`lib/features/chat/chat_screen.dart`

### 2.1 结构（从上到下）

| # | 区块 | 内容 | 出现条件 |

> 注意顺序：**附件草稿在工具芯片之上、输入框之下**。也就是说「待发的东西」永远贴着输入框，工具是它上面的一层。

### 2.2 AppBar 细节

- 标题用 `titleMedium` w600；副行是**按钮**（`_ModelPick`），点开底部弹层选平台和模型，**只影响当前会话**。
- 更多菜单只有一个「设置」项（跳到设置页）。这里刻意保持极简，不要往这里加按钮。
- 分支切换 `‹ 1/2 ›` 是**小而扁的圆钮（26×26）+ `labelSmall` 文本**，位于更多按钮左侧，只在最后一条消息存在多分支时出现。

### 2.3 本会话用量条（`session_usage_bar.dart`）

- 一整条浅底（`surfaceContainerHighest` @50%）圆角 10，左侧 16 图标，主文案 `bodySmall`，token 数 `labelSmall`（更淡）。
- 文案：`本会话 占用 10% · 缓存命中 33%`。无数据统一显示 `—`；读取中「本会话 正在读取…」；失败「本会话 读取失败：…」（图标转红）。
- 占用率**可以超过 100% 并照实显示**（超窗了也要让用户看见）。
- 占用 = 最近一次请求的 prompt tokens ÷ 设置里的上下文窗口；缓存命中 = 本会话累计。
- **不建议在这里放「重置」**：曾有过，因误触被移除（重置入口在设置 → 用量）。

### 2.4 消息气泡

| | 用户 | 助手 |
| --- | --- | --- |
| 对齐 | 右 | 左 |
| 底色 | `primaryContainer` | `surfaceContainerLow` |
| 文字色 | `onPrimaryContainer` | `onSurface` |
| 圆角 | 16 / 16 / 4 / 16（**右下角 4**，尾巴） | 16 / 16 / 16 / 4（**左下角 4**） |
| 头像 | 无 | 左侧 24 圆 + `auto_awesome` 图标（`primaryContainer` 底） |
| 正文 | 可选中纯文本（无 Markdown） | Markdown 渲染 |
| 最大宽度 | 屏宽 86% | 同 |
| 内边距 | 12 / 10 / 12 / 10 | 同 |
| 出错 | — | 描边 `error` 60% + 气泡内底部「⚠ 这条回答中断了」（`labelSmall`，红） |

气泡内部**从上到下**的顺序（助手）：思考过程折叠块 → 「正在思考…」/「正在联网搜索」（正文还空时）→ Markdown 正文 → 附件 → 搜索结果 pill → 错误提示 → 流式小转圈（12px，正文已有内容时）。

气泡**下方**有一行操作（只在助手、且正文非空/流式中/出错时出现），左缩进 30：
朗读（`SpeakButton`，16）→ 复制（16）→ 重新生成（16，流式中禁用）→ 分支切换（密集 26 双钮）。
每个按钮的点击区都是 30×30（`visualDensity.compact`），别按 16 画点击区。

### 2.5 思考过程折叠块（`_ThinkingPanel`）

- **默认收起**，只露一行：`⌄ 思考过程（进行中）` / `⌄ 思考过程（12.3 s）` / `⌄ 思考过程`（图标 15，文字 `labelSmall` 次要色）。流式中右侧再跟一个 10px 转圈。
- 点整行展开/收起（无动画，`setState` 直接切）。
- 展开后的内容区：`surfaceContainerHighest` @50% 底 + 8 圆角 + **左侧 2px `outlineVariant` 竖线** + 8 内边距，正文 `bodySmall`、行高 1.5、`onSurfaceVariant`，可选中。
- 折叠是刻意的：思考往往比答案长，默认展开会把答案挤出屏幕。

### 2.6 搜索结果 pill 与来源面板

- 正文下方一枚小胶囊：`travel_explore`（14，`primary`）+「N 个网页」（`labelMedium`，`primary`），底 `surfaceContainerHigh`，圆角 14，内边距 10 / 5。
- 点胶囊 → 底部弹层（最多 70% 屏高）：标题「搜索结果（N）」→ 每条：标题 1 行（`primary`）+ 摘要 2 行（`labelSmall`）+ 右侧 `open_in_new` 图标。
- 点某条 → 关弹层并**用外部浏览器打开**（不是内置 WebView）。
- 这是「官方样式」的刻意模仿：正文里不放全量链接列表，只放一个计数入口。

### 2.7 Markdown 与代码块

- GFM（表格/删除线/任务列表/脚注）+ 公式（`$…$` / `$$…$$`，可横向滚动）+ mermaid 围栏（`MermaidBlock`：用一个 1×1 的离屏 WebView 跑 mermaid 渲染成 SVG，再用 `flutter_svg` 显示；渲染结果缓存，失败有错误文案）。
- **代码块结构**：容器圆角 12、描边 `outlineVariant` 60%、上下外边距各 10；顶部 34 高的标题栏（`surfaceContainerHigh`）左侧语言名（`labelSmall` 11 / 字距 0.6 / `onSurfaceVariant`），右侧 34×34 图标按钮（`copy_rounded`，点击后变 `check_rounded` + `primary` 色，2 秒复位）；代码区 padding 12、**横向滚动不换行**、滚动条 3px，等宽 12.5 / 行高 1.55。
- 语言名取模型写的原始标记（即使高亮器不认识也照原样显示）；空语言显示「代码」。
- 高亮主题：浅色 `atom-one-light`、深色 `atom-one-dark`；容器的 root 背景被强制透明，由外层 Container 上色（否则会出白底）。
- **正文超 12,000 字先渲染纯文本**（行高 1.6），下方给一行入口：`⌄ 展开完整排版（12.3k 字）`（`labelSmall`、`primary` 色、15 图标），点了才走 Markdown。这是性能兜底（全量解析在 27k 字级别会一帧数秒、真机 ANR），**不要为了好看去掉**。

### 2.8 输入区与工具芯片

**工具芯片行**（`_ComposerTools`，源码 `chat_screen.dart:2360`）：

| 添加附件 | 「添加附件」 | 不带选中态 | 打开附件菜单（拍照/从相册/选文件） | — | 图标 50% 透明 + tooltip 说明「暂不支持附件，请改成发文字」 |

芯片视觉（v3.1 定稿，与设计库 `SPEC.md` §4.8 一致）：高 **32**、左右内距 **12**、圆角 `rChip`、图标 **15**、文字 **12**；开态 = `primaryContainer` 底 + `onPrimaryContainer` 字 + 皮肤标题字重；关态 = **透明**底 + 1px `outlineVariant` 描边 + `onSurfaceVariant` 字。触摸框 48（上下各 8），但**底色只画在 32 的本体上**，触点框本身不着色。

**按压态（v3.1 新增，别退回 Material 默认）**：关态按下时芯片本体底 = `surfaceContainerHigh`，过渡 120 ms；开态按下保持 `primaryContainer`（不加深）。**禁止** Material 默认的 `highlightColor` 与 `InkSparkle/InkRipple` 水波纹 —— 它们按 **48dp 触点框**铺一层深色，比 32 的本体大一圈，点一下就是「灰色遮罩闪一下」。工程落地：`InkWell(splashFactory: NoSplash.splashFactory, splashColor: Colors.transparent, highlightColor: Colors.transparent, onHighlightChanged: …)`，背景自己按 `_pressed` 在 `transparent` / `high` 之间切。

> ⚠️ **深度思考 / 思考强度 / 上下文预算都是「会话级」**：芯片显示的是**当前生效值**（会话覆盖 ?? 全局默认），改它不会写回设置页。设置页里那三项只是**新会话的默认值**。这条是产品约束，视觉改版不能把它变成全局开关。

**输入栏**（`_InputBar`）：

- 左：＋（`add_circle_outline`，不支持附件时 40% 透明）。
- 中：`TextField`，1–6 行自适应，圆角 14，填充 `surfaceContainerHighest`；聚焦时边框 `primary` 1.2px，未聚焦 `outlineVariant`。键盘回车 = 换行（`TextInputAction.newline`），**发送只能点按钮**。
- 右：麦克风（`mic_none_rounded`）↔ 切到语音模式后变键盘图标（`primary` 色）。
- 最右：**发送/停止按钮**（`IconButton.filled` 圆形）：
  - 可发送 = 有文字或有附件 → `arrow_upward_rounded`；不可发送 = 禁用（灰）。
  - 发送中（已点但未开始流式）= 16px 转圈，禁用重复点击。
  - **流式中 = 变成 `stop_rounded` 停止按钮，底 `errorContainer`，图标 `onErrorContainer`**。停止按钮始终可点。
- 语音模式：输入框换成 44 高的「按住说话」条（录音中底 `errorContainer` + `error` 描边 + 麦克风实心 + 提示文字；转写中显示 14px 转圈）。

**附件草稿**（`_PendingChips`）：每个 52×52，右上角 ✕ 移除；上传中顶部一行 12px 转圈 +「正在上传附件…」（`labelSmall`）。附件是否可用取决于平台：只有 DeepSeek Files API 支持附件，其它平台加附件会 toast 提示改成发文字。

### 2.9 流式、发送中、停止

| 阶段 | UI |
| --- | --- |
| 已点发送，等首包 | 发送按钮转圈；输入框内容保留到请求确认 |
| 流式中（正文还空） | 气泡内一行：12px 转圈 +「正在思考…」或「正在联网搜索」（`bodySmall` 次要色） |
| 流式中（正文已有） | 正文底部 12px 小转圈；发送按钮变停止；**自动跟随底部**，但用户上翻时暂停跟随并出现「回到底部」圆钮 |
| 停止 | 点停止 → 保留已生成内容，消息打上「中断」标记（`message.error`）→ 气泡内显示「这条回答中断了」 |
| 失败 | 顶部错误条（`errorContainer`，可重试/关闭）+ 该条消息标红边 + 「这条回答中断了」 |

### 2.10 长按菜单与编辑

长按**任意气泡** → 底部菜单（带拖拽把手）：

| 消息类型 | 菜单项 |
| --- | --- |
| 用户 | 复制 / 编辑（副标题「以这条回复的问题重新生成一版，旧回答会留在分支里」）/ 删除（红色） |
| 助手 | 复制 / 重新生成 / 切换分支（有分支时，副标题「第 1 / 2 个分支」）/ 删除（红色） |

- 「编辑」= 弹窗改文字 → 以该问题的**新版本重新生成**，旧回答保留成分支（不销毁）。
- 「删除」= 确认「删除这条消息？这条消息及其之后的所有分支都会被删除，无法恢复。」
- 复制走系统剪贴板 + toast「已复制」；没内容时 toast「没有可复制的内容」。

### 2.11 空会话（`_EmptyChat`）

64 圆底（`primaryContainer`）+ `graphic_eq_rounded` 图标 →「问点什么」（`titleMedium` w600）→ 一行次要说明（「点右下角「新对话」开始，或从设置里导入 DeepSeek 的导出包」）→ 3 个建议胶囊（`ActionChip`）：
「帮我把下面这段话润色一下：」/「用三句话解释一下量子纠缠」/「帮我写一个 Python 脚本，批量重命名文件」。
点建议 = **直接发送**（不是只填进输入框）。第 1 条是半句，暗示用户接着写。

> 这行说明文案是从会话空态复制过来的，在聊天页里语义略怪（会话已经存在了）。建议设计师改写，但「引导去导入」的意图要保留。

### 2.12 空态与边界

| 情况 | 表现 |
| --- | --- |
| 首次加载（无缓存） | 居中转圈 |
| 无消息 | 聊天空态（见上） |
| 历史很长 | 只渲染最近 12 条；上方有「加载更早」，每次 +24 条；滚到顶再点才加载 |
| 单条正文极长 | 先纯文本 +「展开完整排版」 |
| 代码行极长 | 横向滚动，不换行不裁剪 |
| 表格很宽 | Markdown 表格按可用宽度压缩，超出部分横向滚动 |
| 附件不支持 | 芯片仍显示但变灰，点击无反应，tooltip 解释原因；输入栏 ＋ 40% 透明 |
| 平台不支持思考/搜索 | 对应芯片禁用，文案改成「不支持 …」 |
| 未配置平台 | 加附件/发送时 toast 引导「设置 → AI 平台」 |

## 3. 设置页

来源：`lib/features/settings/settings_screen.dart`

### 3.1 结构（从上到下，7 个分组）

| 分组标题 | 内容 | 交互 |
| --- | --- | --- |
| **AI 平台** | `ProviderSection`：平台列表 +「添加平台」按钮 | 点平台 → 编辑弹层（名称 / Base URL / API Key / 协议（OpenAI 兼容 / Anthropic 兼容）/ 模型（可从 `/models` 拉取）/ 是否支持推理、联网、思考）；删除平台有确认（「「X」的 Key 和配置会从本机删除，无法恢复。」） |
| **对话默认** | 系统提示词 / 上下文预算 / 思考强度 / 深度思考开关 / 联网搜索开关 / 记忆与回忆 / 情绪 / 人格 / 清空记忆数据 | 前三个是 ListTile+弹窗；中间四个是 `SwitchListTile`；最后一项红字危险操作 |
| **用量** | 用量统计（合计）/ 按会话 / 余额 / 上下文窗口 | 前两个是统计与重置；「上下文窗口」可改（影响占用率分母） |
| **后台任务** | `_BackgroundTasksSection` | 只读展示，见 §3.2 |
| **外观** | 主题（浅色 / 深色 / 跟随系统） | 三选一弹窗，选中项 `check_circle` + `primary` |
| **数据** | 「数据全部存在本机」说明 + 角色卡（进二级页）/ 导入历史对话 / 导出备份 | 角色卡带 `chevron_right` |
| **关于** | 应用名「Keepsake（留声）」+ 版本号 +「数据全部存在本机」 | 只读 |

分区标题样式：`labelLarge` w700、`primary` 色，内边距 16 / 20 / 16 / 6 —— 是全 App 唯一用 w700 的地方。

### 3.2 后台任务区块（`_BackgroundTasksSection`，源码 `settings_screen.dart:503`）

| 状态 | 表现 |
| --- | --- |
| 导入运行中 | 行：`cloud_download_outlined` 图标 + `progress.label`（如「正在导入 12 / 300」）+ 下方 3px 进度条 + 当前会话标题 |
| 导入有失败（未运行） | 行：红色 `error_outline` + 「有 N 条没导上」 |
| 补建角色卡运行中 | 行：`badge_outlined` 图标 + 「正在补建角色卡：done / total」+ 3px 进度条 |
| 都没在跑 | 一行次要文字「没有正在运行的后台任务」 |

**这个区块只显示、不提供启动按钮**：导入从「数据 → 导入历史对话」启动，补建从会话列表 ⋮ 菜单启动。任务是全局的，切页面不中断。

### 3.3 模型 / 平台

- 平台是**多套并存**的（DeepSeek 官方 + 任意 OpenAI 兼容 / Anthropic 兼容端点），每套带自己的模型名、能力开关。
- 能力开关（推理 / 联网 / 思考）**决定聊天页对应工具芯片是否可用**，是「平台能力」而非「用户偏好」。
- 切换只影响**当前会话**（在聊天页切），设置页改的是默认。

### 3.4 角色卡

- 二级页 `CharactersScreen`；入口行副标题「按角色隔离记忆、情绪、人格；导入时可按话题自动建卡」。
- 角色卡 = 记忆隔离边界：记忆/情绪/人格挂在卡上，跨卡不召回。
- 导入历史对话时会问怎么建卡：自动按话题分组（推荐）/ 全部并到一张 / 每个会话一张（不推荐）。

### 3.5 导入 / 导出

- **导入历史对话**：三种入口 —— 选本地 ZIP（「已经下载到手机里的 DeepSeek 导出包」）/ 粘贴下载链接（自动下载并导入）/ 发现下载链接。导入是**后台分批**的，同 id 跳过、追加不覆盖，中断可续跑。
- **导出备份**：把本机全部会话导成 ZIP（含图片原件），格式与 DeepSeek 导出一致。
- 两者都可能耗时数分钟 —— 设计上必须保证「离开页面不中断、进度能在后台任务里看到」。

### 3.6 主题

- 三个选项：浅色 / 深色 / 跟随系统。
- 切换立即生效（`settingsProvider` → 根 `MaterialApp`），列表行副标题显示当前值。
- **深色模式的具体配色还没采样过**，见 `tokens.md` §1。

### 3.7 空态与边界

| 情况 | 表现 |
| --- | --- |
| 没有配置任何平台 | ProviderSection 只剩「添加平台」按钮 |
| 协议/模型不合法 | 保存时校验并 toast，不静默失败 |
| 系统提示词为空 | 副标题「留空则使用默认提示词」 |
| 上下文预算 = 0 | 显示「上下文：不限制」，语义是「全部历史」 |
| 思考强度弹窗 | 每项两行：强度名 + 一句说明（「更快、更省，适合日常问答」/「默认，平衡速度与推理」/「给更多思考预算，适合难题/写作」） |
| 版本号取不到（桌面/测试） | 副标题退回「数据全部存在本机」 |

## 4. 关键状态枚举

这套 App 没有集中的状态枚举类型，状态由 `ChatUiState` 的布尔字段组合表达。设计稿至少要为下表每种组合出一版。

| 状态 | 聊天页怎么表达 | 会话列表怎么表达 | 设置页怎么表达 |
| --- | --- | --- | --- |
| **空** | `_EmptyChat`：图标 +「问点什么」+ 说明 + 3 个建议胶囊 | 大图标 +「还没有会话」+ 导入引导；FAB 保留 | 后台任务：「没有正在运行的后台任务」；AI 平台：只有「添加平台」 |
| **加载中** | 首次加载：居中转圈（无骨架屏）；用量条：「本会话 正在读取…」 | 居中转圈（无骨架屏） | 用量统计行：「正在读取…」 |
| **流式中** | 无正文：转圈 +「正在思考…」/「正在联网搜索」；有正文：底部 12px 转圈；发送键变**停止**（`errorContainer` 底）；自动跟随 + 上翻暂停 + 回到底部钮 | — | 导入/补建行 + 3px 进度条 |
| **失败** | 顶部错误条（`errorContainer` + 重试 + 关闭）；消息级：红描边 +「这条回答中断了」；用量条：红图标 +「读取失败：…」 | 整页错误态：红图标 +「加载失败」+ 详情 + 重试；单条操作失败走 toast | 用量行「读取失败」；导入失败行「有 N 条没导上」 |
| **离线** | **没有专门的离线态**。离线表现为请求失败 → 走「失败」那一套。本地已有消息照常可读、可搜索 | 同理：本地数据照常显示；导入/导出会失败并 toast | 同理 |

> 关于「离线」：如果要补一个真正的离线态，建议做成**顶部细条**（不是弹窗），文案类似「当前没有网络，已显示本机记录」，并**不要禁用输入框**——用户可以继续写草稿。这是待设计项，代码里目前没有。

| 生成中（无正文） | 正在思考… / 正在联网搜索 | `onSurfaceVariant` |
