## 1. 这个包是什么

Keepsake 是一个本地优先的 AI 对话 App：所有对话、记忆都存在手机上，可导入 DeepSeek 的历史导出包，支持多平台（DeepSeek 官方 / 任意 OpenAI 兼容端点）和会话级的分支、思考、联网搜索。

这个包**只包含设计需要的三样东西**：

1. **真实的设计 token**（`tokens.md`）—— 不是推测，是从主题源码 + 真机截图采样出来的。
2. **逐屏 UI 逻辑**（`ui-logic.md`）—— 每屏的结构、手势、数据来源、空态、边界。
3. **参考实现源码**（`code/`）—— 关键组件的真实 Flutter 代码，只看不改。

**没有的东西**：没有 Figma 源文件、没有字体文件、没有图标资源包。图标全部是 Material Symbols（`Icons.*` 轮廓系），如果要做自定义图标需要单独立项。

## 3. 必须保留的交互约束（**改视觉不能改这些**）

这些不是审美偏好，是踩过坑的功能约束。每一条都有代价，改之前请先聊。

### 3.1 编辑与多选

| # | 约束 | 为什么不能改 |
| --- | --- | --- |
| 1 | **多选入口在会话列表左上角**（`checklist` 按钮），**不在会话详情/对话框里** | 用户明确要求过。旧版是「批量删除对话框」（见 `screenshots/t-batch2.png`），已废弃 |
| 2 | 多选支持**单选/多选/全选**；顶栏是「已选 N + 全选 + 导出 + 删除」 | 全选和「全不选」是同一个按钮切换；0 选中时导出/删除必须禁用 |
| 3 | 多选态下**禁用左滑删除**、**隐藏 ⋮ 菜单** | 防误删、防抢点击 |
| 4 | 导出必须**同时支持**「存到手机」和「分享」 | 一个是离线备份，一个是发到别的 App，缺一个就有人用不了 |
| 5 | 长按消息 = 出菜单（复制/编辑/重生成/切分支/删除） | 所有消息级操作都挂在这里，没有第二个入口 |

### 3.2 会话级 vs 全局

| # | 约束 | 为什么不能改 |
| --- | --- | --- |
| 6 | **深度思考 / 思考强度 / 上下文预算是「会话级」**，聊天页芯片改的是当前会话；设置页只管**新会话的默认值** | 用户明确要求「对话页开关只作用于当前会话，不写全局设置」。视觉上如果做成"全局开关"的样子，会误导 |
| 7 | 平台/模型选择在**聊天页顶栏副行**，改了只影响当前会话 | 同一个 App 里多平台并存，不能做成全局设置 |
| 8 | 「后台任务」区块**只显示不启动** | 导入从「数据」进、补建从列表 ⋮ 进；设置页加启动按钮会造成重复入口 |
| 9 | 本会话用量条**不放重置按钮** | 曾有过，因误触被移除（重置在设置 → 用量） |

### 3.3 性能与长内容

| # | 约束 | 为什么不能改 |
| --- | --- | --- |
| 10 | **单条正文超 12,000 字先渲染纯文本**，用户点「展开完整排版」才走 Markdown | 全量解析在 27k 字级别一帧要数秒、真机 ANR。这是硬兜底 |
| 11 | 代码块**必须横向滚动，不换行、不裁剪** | 长行被硬裁是很早以前被明确否掉的问题 |
| 12 | 聊天气泡只渲染最近 12 条，向上「加载更早」每次 +24 条 | 老会话动辄几百条，一次全建会卡死 |
| 13 | 流式输出时**自动跟随底部**，用户上翻则暂停并出现「回到底部」圆钮 | 用户看历史时不能被强行拽回底部 |

### 3.4 手势

| # | 约束 | 为什么不能改 |
| --- | --- | --- |
| 14 | 工具芯片「深度思考」**长按 = 改思考强度** | 这是唯一的强度入口，视觉改版不能把它藏掉或改成点击 |
| 15 | 长按会话行 = 进多选并选中该行 | 和 ⋮ 菜单是两条并行路径，都要保留 |
| 16 | 左滑删除带确认（不能做成滑一下就删） | 会话不可恢复 |

### 3.5 语义色

| # | 约束 | 为什么不能改 |
| --- | --- | --- |
| 17 | 用户 = `primaryContainer` 气泡，助手 = `surfaceContainerLow` 气泡 | 气泡上不写名字、不加图标，「有色 / 无色」是唯一的说话人线索 |
| 18 | 删除/清空类操作 = `error` 系 | 不能换成品牌绿 |
| 19 | 「选中」必须同时具备：`primaryContainer` 底 + 描边 + 加粗 | 只留一项会削弱可辨识度（选中态在深色下尤其依赖描边） |

## 4. 可以自由改的视觉

- **主色种子 `#2F6B5F`**：换掉整个 App 的配色会跟着变。唯一要求：`primaryContainer`（用户气泡）和 `surfaceContainerLow`（助手气泡）明度差 ≥ 8%，否则分不清谁在说话。
- **圆角、间距节奏、字重、图标风格、按钮形状**。目前是 16 系（卡片/气泡）+ 12/14 系（输入/芯片/代码）两套并存，你可以统一。
- **阴影策略**：现在是「零阴影 + 底色分层」的扁平路线，加投影也行，但只建议加给浮层（弹层/FAB），别加给卡片和气泡。
- **动效时长与曲线**：现在全是默认曲线（滚动 220ms、跟随 120ms 等），没有定制转场。
- **代码块高亮主题**：现用 `atom-one-light` / `atom-one-dark`。**前提是不能刺眼**——之前用过 github 那套荧光红被明确否掉。
- **文案**：见 `ui-logic.md` §4.1 的速查表。改写时注意中文排版（中英之间空格、标点用全角）。

## 7. 已知缺口 / 待补

| 项 | 状态 |
| --- | --- |
| 下拉刷新 | **未实现**（工程里没有任何 `RefreshIndicator`）。要不要做，需要先定刷新语义 |
| 深色模式 | 只有代码实现，**没有采样过的色值**（`tokens.md` 里标了「推导」的就是没截到的） |
| 搜索命中定位 | 点搜索结果只打开会话，不跳到那条消息 |
| 离线态 | 没有独立表达，离线 = 请求失败，走错误条那一套 |
| 平板/横屏 | 没有专门布局，气泡最大宽按屏宽 86% 算，横屏会过宽 |
| 无障碍 | 没做 `Semantics`，部分图标只有 tooltip |
| 大字号 | 没测过系统字号 1.3× / 1.5× 下的断行 |

以上都在 `ui-logic.md` §5 有展开说明。
